# Conformance: greedy battle AI (`battle_ai.json`)

Status: vectors generated by `h3re.vectors_ai.generate()` (orchestrator wires it into
`vectors.generate()`); Kotlin port `h3.sim.BattleAi`; test `BattleAiTest`. Python
`tools/h3re/h3re/battle_ai.py` is the oracle (ADR-0004, ADR-0007).

## What is pinned

- Stateless `choose(state, side=None)`: seed = first 16 hex digits of the state hash as an
  unsigned 64-bit integer; tie-break stream `derive_stream(seed, "ai:<side>")`, created only
  when more than one candidate ties. Before `Begin` the result is `Begin`. Past round 8 the
  Defend fallback is disabled (Wait, else the closest Move).
- Stateful `GreedyAI(ai_seed)`: one stream `derive_stream(ai_seed, "ai:<side>")` per side
  (kept across calls) and a per-side count of consecutive Defends; at `MAX_DEFENDS = 2` it
  stops defending (Wait, else the closest Move). The count resets on any other command.
- Scoring: expected damage from `resolve_damage(strike_context(..), EXPECTED)` (an integer),
  times 2 for a double striker or double shooter, capped by the target's total HP; melee
  subtracts the expected retaliation (capped by the attacker's HP) when the target survives,
  can retaliate and the attacker does not prevent it; a kill adds 1. Highest score wins;
  ties go to the stream. No floating point anywhere.
- The AI never draws from `battle:<id>`; the vectors assert the stream state is unchanged by
  both AI calls at every step, and the final stream position is recorded.

## File layout

`{format, max_defends, stateless_defend_round, packs{battle_policy, bad_morale_numerators,
rules_hash, rules}, games[]}`. A game: `name`, `scenario{kind, seed, policy, policy_kwargs,
battle_id, master_seed, stream_domain, stream_id, ai_seed, perturbed}`, `initial{canonical,
sha256}`, `steps[]`, `final{sha256, winner, steps, round, rng_state, rng_inc}`.
A step is one decision point (the first is `Begin`): `side`, `defends_before`, `sha256` of the
state, `stateless`, `stateful`, `applied` (commands in `soak.encode_command` form) and, every
7th step and the first three, `canonical` (the state text). "Perturbed" games apply a random
legal command (from `derive_stream`) every 4th step instead of the AI's choice.

Scenario kinds: `soak` (random armies), `flat` (morale and luck 0), `ability` (all creature
flags), `tie` (speed ties), `wall` (full obstacle column: exercises Defend cap, Wait and
closest-Move fallbacks). Policies: default, alt-order, vcmi-like, strict, mix-fifo, mix-speed,
mix-alt.

## Kotlin contract

`BattleAiTest` checks: (1) stateless choose equals the record on every canonical state;
(2) each game is replayed from `initial` with the battle stream derived from the scenario;
at every step the state hash, side, Defend count, stateless and stateful choices match, the
battle stream is untouched by the AI, and the final hash, winner, round and stream position
equal the record. Vectors are never edited by hand.
