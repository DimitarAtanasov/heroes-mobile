# Conformance: TXT reader and creature content loader (Kotlin port)

Companion to `conformance.md` (not edited). Python (`h3re.txt`, `h3re.content`) is the oracle
(ADR-0004); Kotlin is `h3.sim.Txt` (`Txt.kt`) and `h3.sim.Content` (`Content.kt`).

## Vectors
Generated by `h3re/vectors_txt.py` (`generate() -> {filename: object}`), SYNTHETIC only (invented
creatures; no game data, law 9). Files: `txt.json`, `content.json` in
`android/sim/src/test/resources/vectors`. Integration: `vectors.py::generate()` must also emit
`vectors_txt.generate()` through `_dump` (like `vectors_battle`); until then
`tests/test_vectors_txt.py` checks the committed files directly. Never edit vectors by hand.

- `txt.json`: `cases[]` of `{name, data_hex, header_rows, [encoding, lenient_newlines, quoting,
  max_bytes, max_lines], expect:{header, rows} | error}`. Error categories: `header_rows`,
  `too_large`, `too_many_lines`, `unknown_encoding`, `decode`. Includes 240 fuzz cases from a fixed LCG.
- `content.json`: `mapping` (data/txt_maps/crtraits.json) and `cases[]` of `{name, data_hex, roe,
  encoding, expect:{creatures, extras, unknown} | error:{category,row,column}}`. Categories:
  `table`, `header`, `missing_cell`, `empty_cell`, `not_integer`, `schema`, `duplicate`, `no_rows`
  (`mapping` is Kotlin-only, tested directly). Kotlin asserts category, row, column and that the
  message names row/column; it does not compare message text.

## Kotlin notes and known divergences
- Encodings: cp1252 (default), cp1250, cp1251, gbk, utf-8 (plus aliases); anything else is
  `unknown_encoding`. Decoding is strict (REPORT). Single-byte undefined bytes (e.g. cp1252 0x81)
  are errors in both; GBK edge bytes (e.g. 0x80) were not vectored and may differ between JDK and CPython.
- Content integers are `Long`; overflow saturates (schema error for validated fields) where Python
  accepts arbitrary ints in `extras`. Only ASCII digits (with sign and single underscores) parse.
- Creature order is UTF-16 code-unit order (Python: code point); same for BMP names.
- The Kotlin datapack validator does not exist yet: `DefaultCreatureValidator` implements the creature
  range checks of `datapack._check_creatures` behind `CreatureValidator`. Replace with the datapack
  validator when it lands.
- `CreatureMapping.fromTree` takes a parsed JSON tree (main source has no JSON parser); tests use MiniJson.
