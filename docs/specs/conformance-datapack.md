# Conformance: data-pack loader (`vectors/datapack.json`)

The Kotlin loader `h3.sim.Datapack` (`android/sim/.../Datapack.kt`) is a port of
`tools/h3re/h3re/datapack.py` (docs/specs/datapack.md). Python is the oracle (ADR-0004,
ADR-0007). Vectors come from `tools/h3re/h3re/vectors_pack.py` (`generate()`; the orchestrator
wires it into `vectors.generate()`), never by hand.

## API (Kotlin)

`Datapack.parseRules(text)`, `parsePolicy(text)`, `parseCreatures(text)` take file text and return
`RulesDoc` (`pack: RulesPack`, `contentHash`), `PolicyDoc` (`values`, `contentHash`,
`battlePolicyPack(rules)`: the existing `BattlePolicyPack`) and `CreaturesDoc`
(`creatures: List<BattleCreature>` sorted by name). `Datapack.packHash(rules, creatures)` is
Python's `DataPack.content_hash`. Failures throw `DatapackError(category, message)`.

## Hashes

- rules: SHA-256 of canonical JSON `{"creatures":[],"rules":{...}}` (Python `load_rules_pack`);
  fractions hash as written in the file (not reduced), parsed values are reduced.
- policy: `{"battle_policy":{...}}`.
- creatures: the pack hash with the shipped rules, `{"creatures":[...],"rules":{...}}`; creatures
  sorted by name (code point order), `hates` sorted, only keys present in the file.

## File layout

`shipped` (three packs: text, hash, parsed; `pack_hash`, `canonical_policy`), `valid` (variants:
key order, formatting, creature order, boundary values, non-ASCII names; each has `hash` and
`parsed`; `same_hash_as: "shipped"` or a `group` whose members must share a hash), `invalid`
(`kind`, `text`, `category`, `message`).

## Error classes

Messages equal Python's `DataPackError` text (path first, e.g. `creatures[0].hp: 0 out of range
1..100000`). JSON-level errors carry the file name prefix (`rules.json: ...`, duplicate keys are
prefixed twice, as in Python). Categories: `invalid_json` (compared by category only: parser texts
differ), `duplicate_key`, `float` (any `.`/`e`/`E` literal, NaN, Infinity), `type` (includes
bool-as-int), `unknown_key`, `missing_key`, `range` (ints capped at 2^31-1), `length`, `enum`,
`schema_version`, `table` (level 0 not `[0,1]`, non-decreasing), `distinct`, `dmg_order`,
`duplicate_name`, `unknown_creature`, `empty`.

Invalid cases are generated by single-point mutation of each shipped pack (every key deleted, an
unknown key added, every container and leaf replaced by other types, floats, bools, 2^31, negative,
huge) deduplicated by message, plus hand-written cases and raw-text cases. Python asserts every
case fails with the recorded message; Kotlin asserts the same category and message.

## Known limits

Python-only text edge cases are not modelled: `repr` of non-printable characters in names inside
error messages; Unicode whitespace beyond `String.isBlank` for the blank-name check.
